### **参数**

| 参数名      | 描述             | 类型    | 默认值 |
| ----------- | ------------    | ------- | ------ |
| always-show | 总是显示提示     | boolean | false  |
| disabled    | Tooltip 是否可用 | boolean | false  |
| effect      | 主题            | string   | light  |
| placement   | Tooltip 的出现位置  | string   | top-start  |
| enterable   | 鼠标是否可进入到 tooltip 中  | boolean   | false  |
